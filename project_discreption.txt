☕ Starbucks Beverage Analytics Dashboard — Power BI

1. Project Overview

Starbucks Beverage Analytics Dashboard is an interactive Power BI business intelligence project designed to analyze beverage-level data and identify patterns in calories, sugar, caffeine, beverage categories, and product distribution.

The dashboard transforms raw beverage data into an easy-to-understand visual report that can help business stakeholders evaluate product characteristics, compare beverage categories, identify high-calorie/high-sugar products, and understand caffeine trends.

Main Objective

The primary objective of this project is to answer questions such as:

* Which beverage categories have the highest average calories?
* Which categories contain the highest caffeine levels?
* What is the average sugar content across beverages?
* Which beverages have the highest caffeine?
* How are beverages distributed across different categories?
* Which products may require nutritional optimization?
* How can beverage-level data support product and marketing decisions?

5. Data Cleaning & Transformation

Before creating the dashboard, the data was prepared using Power Query.

Data preparation steps

1. Imported the beverage dataset into Power BI.
2. Reviewed column names and data structure.
3. Removed unnecessary fields.
4. Checked for missing/null values.
5. Corrected data types.
6. Standardized categorical values.
7. Converted numerical columns into appropriate numeric data types.
8. Checked duplicate records.
9. Created required calculated fields/measures.
10. Loaded the cleaned dataset into the Power BI data model.

This step ensured that the data was suitable for accurate visualization and analysis.
